Connect Claude

no_human codes with Claude. Connect it once — with your Claude subscription, or with your own Anthropic API key. The credential is stored only on this computer, in ~/.no_human/.env.

First, on this computer:
    Credential type
    1. In a terminal, run claude setup-token
    2. Sign in when the browser opens
    3. Copy the token it prints, and paste it below
    Optional: coding with the OpenAI (codex) backend

    no_human's coder can run on OpenAI's codex instead of Claude — Claude is still used for review and planning, so this is additional, not a replacement. Two ways to connect it, or skip and code with Claude.

    Run codex login in a terminal — no_human never stores your OpenAI login.

    Bills your OpenAI platform account (platform.openai.com). Stored only on this computer, in ~/.no_human/.env — never in config.yaml.

    Use the token from claude setup-token. Have your own Anthropic API key instead? Switch the credential type above.
